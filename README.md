# Orla Ponta Verde

Demonstração interativa de uma experiência residencial em Ponta Verde, Maceió. A imagem, as plantas, os pavimentos e as características das unidades são ilustrativos e não foram verificados. A visualização principal usa uma imagem estática com áreas clicáveis; não é um modelo 3D ou passeio virtual.

O site é estático. Para executá-lo localmente, use `python3 -m http.server 8000` nesta pasta e abra http://localhost:8000.
