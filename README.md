# Orla Ponta Verde

Demonstração independente do Five Flex Life, em Ponta Verde, Maceió. A maquete esquemática permite girar, aproximar e abrir a planta de navegação pelo 11º pavimento. É possível selecionar as unidades 1103 e 1108, comparar as áreas e consultar as plantas publicadas.

A planta de navegação indica posições aproximadas, sem escala. Os preços são os da tabela da Hilton Imóveis de 02/07/2026. O site apresenta as fontes e os créditos das fotografias. Os JPEGs da galeria foram otimizados para a web e seguem a licença CC BY-SA 4.0 das imagens originais.

Para executar localmente, rode `python3 -m http.server 8000 --directory dist` e abra http://localhost:8000. Mantenha `dist` e `docs` sincronizados. O repositório público `pedromagalhaesbatista/orla-ponta-verde` publica a versão estática pela raiz da branch `main`.
