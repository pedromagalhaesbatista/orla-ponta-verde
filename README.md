# Orla Ponta Verde

Demonstração interativa de uma experiência residencial em Ponta Verde, Maceió. A imagem, as plantas, os pavimentos e as características das unidades são ilustrativos e não foram verificados. A maquete 3D permite girar, aproximar e selecionar pavimentos. As unidades disponíveis para demonstração ficam nos pavimentos 3, 5, 8 e 12. A vista aérea é uma imagem conceitual.

O site é estático. Para executá-lo localmente, use `python3 -m http.server 8000` nesta pasta e abra http://localhost:8000.
